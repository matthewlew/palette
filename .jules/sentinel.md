## 2025-02-05 - PostgREST Filter Injection and SVG XSS via JSONB
**Vulnerability:** Found two vulnerabilities. First, user search terms in `src/components/SearchBar.tsx` were directly interpolated into a string passed to Supabase's `.or()` filter. Second, in `supabase/functions/preview/index.ts`, the `offsets` JSONB array was interpolated into a raw SVG text string as the `offset=""` attribute.
**Learning:** Supabase's JavaScript client parses strings provided to `.or()` using the PostgREST syntax, meaning characters like `,`, `.`, and logical operators can manipulate the query. Additionally, placing raw, untyped strings from a JSONB column into an SVG string exposes the environment to SSRF or markup breaking payloads (XSS).
**Prevention:** Sanitize user input by stripping characters reserved by PostgREST and LIKE filters (`[,.%_]`) prior to interpolation. For SVG building and JSONB, coerce the JSONB elements explicitly into numbers (e.g. `map(Number)`) before string interpolation to enforce numeric limits.
