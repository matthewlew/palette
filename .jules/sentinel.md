## 2024-05-15 - Path Traversal (Zip Slip / Arbitrary File Download) via Unsafe Slugification
**Vulnerability:** Filenames for downloaded images and ZIP files were generated directly from user-provided gradient names using only `replace(/\s+/g, '-')`. This fails to sanitize path separators like `/` and `\`, allowing an attacker to name a gradient `../../../malicious` and cause the application to generate files like `../../../malicious-1080x1080.png` or include directory traversal entries inside exported ZIP archives (Zip Slip).
**Learning:** Naive whitespace replacement is insufficient for filename sanitization. Path traversal strings (`../`) contain no whitespace and will bypass the check. When generating ZIP files on the client using libraries like `jszip`, browsers' native download sanitization is bypassed, directly exposing the Zip Slip vulnerability.
**Prevention:** Always use an allowlist approach for filename sanitization, replacing all non-alphanumeric characters (e.g., `replace(/[^a-z0-9]+/gi, '-')`) before using user input to construct a file path or archive entry.
