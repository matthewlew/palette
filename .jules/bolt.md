## 2024-08-04 - Preventing N Re-renders on Tile Component with Custom Comparator
**Learning:** `Tile` components in `Gallery.tsx` receive dynamically generated objects and closures on every render. If we just use `React.memo` without a custom equality comparator, it still re-renders since the reference to the `likes` object changes. We have to explicitly check `prev.likes?.isLiked(prev.gradient.id) === next.likes?.isLiked(next.gradient.id)` and `prev.likes?.countFor(prev.gradient) === next.likes?.countFor(next.gradient)`.
**Action:** Use `React.memo` with a custom equality comparator when passing objects and functions down to list items, and wrap parent event handlers (`openViewer`, `handleDragStartTile`) in `useCallback` to prevent stale closures and unnecessary re-renders.
