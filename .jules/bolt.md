## 2024-05-18 - Prevent O(N) re-renders in list items with closures
**Learning:** In React list components (like `Gallery`), passing inline closures to child components (like `Tile`) causes all items to re-render when the parent's state updates (e.g. during drag-and-drop or hover state changes). This causes a severe O(N) re-render penalty for large lists. Simple object props, such as the `likes` API, can also trigger re-renders even if their internal data regarding the specific list item hasn't changed.
**Action:** Always wrap parent event handlers (`openViewer`, `handleDragStartTile`, etc.) in `useCallback`. For list items with complex prop objects (like the `likes` API), use `React.memo` with a custom equality function that strictly checks the relevant output values (e.g., `likes.isLiked(id)` and `likes.countFor(gradient)`) rather than checking object identity, and ensure other simple props remain referentially equal.
