# Changelog

All notable changes to this project during our sessions will be documented in this file.

## [Unreleased] - 2026-07-27

### Added
- **Back button on the full-screen create feed.** Top-left, same anchor and chevron as the editor's, so "leave this surface" is one gesture everywhere. It only renders where a caller passes `onBack`, so other `GradientPage` surfaces keep their own close chrome.

### Fixed
- **The bottom sheet's grab handle was invisible.** It computed to `height: 0px`: the sheet is a column flex container with a `max-height` while collapsed, so its items shrink to fit, and a 4px handle with the default `flex-shrink: 1` shrank straight to nothing. `flex: none` restores it. That is why the peek read as a cut-off panel rather than something you could pull.
- **Corner buttons no longer stack on each other.** The feed lifts Save to 84px and Grain to 140px to clear the saved-palettes stack, but never lifted Play, so Play (128px) sat *below* Grain and the two overlapped by 32px. Play now takes the same offset at 196px, restoring the even 56px rhythm and clearing the scroll ticker.
- **The Edit FAB no longer covers the keyboard shortcut strip.** Both had claimed the bottom-left corner. The button is now hidden on keyboard devices, where it is redundant twice over — the strip itself reads "E Edit", and clicking the gradient opens the editor. Its media condition is the exact complement of the strip's own, so exactly one is ever on screen.
- **The tab bar fades instead of popping when entering edit.** It used `display: none`, which removes the element from the box tree, so the View Transition could not capture or animate it and the bar vanished in a single frame. It now fades with `opacity` + `pointer-events: none`.

### Removed
- **Boards (collections) deleted.** The feature was unused and its row was the single most expensive block in the mobile gallery header at 86px. Gone: `CollectionsRow`, the `collections`/`activeCollectionId` store slice and its CRUD, the `Collection`/`CollectionLevers` types, the board-detail view, and the destination-aware save on `GradientPage`. Persist migration **v7** deletes the two keys from localStorage; saved gradients are untouched, since a collection only ever held ids pointing into `saved` (covered by a test). `BoardShare` is NOT part of this — despite the name it is the general share/export menu, still used in the feed, gallery and editor.

### Changed
- **The edit sheet is split into Shape and Effect sections.** On mobile a segmented control switches between them; on desktop, where the side panel has the height, both render stacked under headings and there is no switching. This fixes a real dead end: the collapsed peek clipped **214px of controls** behind `overflow: hidden` with no scroll, reachable only by finding a 36×4px grab handle, and nothing on screen said they were there. Both panels stay mounted in either layout — the inactive one is hidden by a class, not unmounted, so desktop can reveal it and no state or focus is lost on switching.
- **The collapsed peek is content-sized instead of a hard-coded height.** Everything below the sections is hidden while collapsed, so the sheet is exactly the handle, the segmented control, and the active section. The two sections differ in height (Shape one 74px row, Effect two rows at 88px), so the rows below start at a different offset per tab and no single pixel value could clear the taller section while stopping short of the colour-stop row for the shorter one. `max-height` remains only as a ceiling so the collapse still animates.
- **Mobile gallery header rebuilt.** It was consuming 324px of an 812px screen — 40% before a single palette appeared — across five stacked blocks, with an action row mixing control heights of 44/29/28/28px on two different baselines. Now three rows totalling **154px (19%)**: tabs; search + layout toggles + share on one line; filter. Every bar control takes a new `--control-h` (36px) with a 44px tap target via the `::after` expansion the chips already used — several controls were previously *below* the 44px minimum while looking larger.
- **All six shapes on one row in the bottom sheet.** The 3-up grid meant two rows of tabs, which is what made the sheet tall and meant the collapsed peek could only ever show half the shapes. Below 768px (wherever the sheet is a bottom sheet rather than the desktop side panel) it is 6-up with smaller squares; the labels still fit — the widest, "Angular", measures 42px at 11px against a ~54px track. The expanded sheet dropped from 68% of the viewport to 40% (tabs 411px to 186px), and the collapsed peek from 166px to 103px, giving the gradient 87%. The preview square is a FIXED 44px rather than a max-width, so the row is exactly as tall at 320px as at 760px — with a cap it grew 6px on a wide sheet and no single peek height could clear the row at one width without slicing it at the other.
- **Filters collapse to a select on mobile.** Fifteen chips wrapped to three rows and cost 90px, and seven of them read "0". Below 640px they become one native `<select>` (OS picker, no overflow, free accessibility); the chip row returns at 640px and up where everything fits at once. Shapes matching nothing are omitted from both — except the currently selected one, which is always kept so it cannot vanish from the control that selects it.
- **The palette title shows it is editable.** It was plain text with no chrome, so the rename was invisible until you happened to click it. Hovering now outlines it as the text field it becomes (`cursor: text`, hairline box in the title's own colour), and the editing state changed from a bottom-border underline to the same full box, so hover to focus is one continuous shape. Hover-capable pointers only, or touch devices latch the outline on after a tap.
- **Export Posts moved into the share menu.** As a labelled 105x29 pill beside the 44x44 icon-only share trigger it was the odd one out in a row where nothing shared a size, and it is a slow bulk action rather than a primary control. It now sits under "More options" with the other bulk exports.
- **Angular honours stop positions** (reversal). Angular spread colours around the circle by index (`i/n`) and discarded positions outright, so dragging a stop emitted byte-identical CSS. Positions now scale by `(n-1)/n`, which reserves the seam its own `360/n` wedge — an evenly spaced ramp lands on exactly the old offsets, so the default is unchanged and only a deliberately uneven ramp differs. Hardened wedges track the same offsets. The original call was made to guarantee N colours read as N equal wedges; that reading survives the scaling, and the inert control did not justify keeping it.
- **Mirror honours stop positions** (reversal). Mirror normalised min–max onto a full 0–100 span before folding, which made it invariant to any shift or stretch of the ramp: `[0,50,100]`, `[10,50,90]` and `[30,65,100]` all produced identical CSS, so dragging either end stop was a no-op. Positions are now halved directly and reflected about the 50% line. A ramp already filling 0–100 is unchanged. The normalisation existed to stop a gap opening at the fold when no stop reached 100; that is now fixed by reflecting the fold stop instead of stretching the ramp to meet it, so a short ramp holds its last colour flat across the middle.
- **Turrell blocks travel nearly the full range.** The extent floor dropped from 0.2 to 0.1, so a stop moves across 90% of the range rather than 80% and the innermost block no longer sits at a fifth of the canvas. It stays well above zero on purpose: layers are blurred 24px by default, so 0.05 (tried, rejected) swallows the innermost colour completely.
- **Drift (the play button) now runs on angular**, which it could not before: every frame used to render identical CSS. Only `square` is still excluded, because Turrell blocks are painted by their own elements and a drifting background-image never reaches them.

### Fixed
- **Four copies of the same geometry, drifting apart.** `gradientColorAt`'s Turrell sampler computed `100 - position * 0.8`, inverting the ramp — it treated position 0 as the outermost layer where the component makes it the innermost, so on-gradient ink was picked against the wrong colour for any square with asymmetric stops. The PNG export compressed angular by `n/(n+1)`, agreeing with neither the CSS nor the sampler, so an exported angular PNG placed every stop differently from the gradient it came from. The export's mirror rebuilt an evenly spaced sequence from hex order, discarding positions. All of these now resolve through the shared `angularSequence` / `mirrorSequence` / `turrellExtent`.

## [Unreleased] - 2026-07-25

### Added
- **Batch Export**: Added an "Export Posts" button to the Gallery header that bundles all saved gradients into a downloadable ZIP file of 1080x1350 PNGs.
- **Instagram Poster Layout**: Added a `post` vignette shape to generate 1080x1350 images for social media sharing. 

### Changed
- **Share Menu Redesign**: Simplified the `BoardShare` dropdown to prioritize a one-tap "Share as Image" and "Copy Link" action, tucking developer/JSON tools behind a "More options •••" overflow menu.
- **Text Alignment**: Changed the poster export text to be left-aligned (6% margin) instead of center-aligned for a more editorial poster quality.
- **Dynamic Text Contrast**: Updated the `titleColorAt` coordinate to sample contrast from the left margin (0.06, 0.5) instead of the dead center (0.5, 0.5) so text remains legible over edge colors (e.g. Hot Terracotta).
- **Turrell Rendering Fix**: Switched Turrell squares from using `ctx.filter = 'blur()'` to `ctx.shadowBlur` during export to prevent rendering bugs on iOS Safari for large canvases.
- **Bug Fix**: Restored missing `index` mapping in `Gallery.tsx` that was causing the cascading animation delay to crash the gallery view.
